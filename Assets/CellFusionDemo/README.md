# 细胞分裂 / 融合试验

适用于 Unity 2022.3 + URP 14 的 2D Renderer。无额外插件，无纹理，无 Bloom 依赖。

## 试跑

1. 等 Unity 导入脚本，先保存当前场景（如果还未命名），然后点击 `Tools > Cell Fusion > Create Demo Scene`。
2. 示例会添加一个新场景并保存至本目录。双击生成的 `CellFusionDemo.unity`，单独打开它，再按 Play。Game 窗口选择 16:9。
3. 左侧为半透明细胞，右侧为白底彩边。选中对应 Quad，在 `Cell Fusion Demo` 组件中调参数。
4. 取消 `Animate`，拖动 `Separation`：0 为融合，1 为分开。`Fusion` 越大，连接颈越宽、开始连接的距离越远。
5. `Rim Width` 控制边缘厚度，`Glow Width` 控制柔光范围，`Opacity` 控制半透明填充，`Nucleus` 控制暗色细胞核。`Speed` 控制循环速度。

菜单以附加方式创建场景以保留原场景；预览时单独打开示例，避免其他场景的相机同时渲染。重复执行菜单会生成新的材质与场景，不覆盖已有文件。

## 原理

每个像素先计算圆的距离场：`d = length(pixel - center) - radius`。
`d < 0` 在圆内部，`d = 0` 在边界。

普通 `min(d1, d2)` 只能形成两个圆的并集，会留下尖角。
本例用 polynomial smooth minimum，把并集的交接处平滑成细胞连接颈。
移动圆心即可产生靠近 → 融合 → 拉伸 → 断开的连续动画。

填充由距离场的内部遮罩决定，彩边由 `abs(d)` 决定，柔光用高斯衰减。
`fwidth(d)` 用于边缘抗锯齿。颜色在合并处按同一个平滑权重混合。
C# 每帧只传递圆心、半径、颜色；轮廓和上色由 fragment shader 计算。

## 对照参考图

- 第一张：本例先实现半透明填充、粉白边缘、暗色核；真正的背景折射、膜上的方向高光、更多层次需要后续加入。
- 第二张：本例验证白底彩边的融合质感。大面积圆角方块与紧密铺排，应将圆 SDF 扩展为圆角矩形或胶囊 SDF，并另外控制每块的位置、尺寸与间隙。独立色块应分别绘制，只有需要融合的形状放进同一组距离场。

这是视觉试验，不会自动生成 Collider2D，也不是流体或生物物理模拟。
当前最多支持 8 个圆；脚本传入 3 个。增加数量会增加每像素计算量。
使用 Quad + MeshRenderer；示例是 Unlit，不接受 Light2D。坐标按 Quad 尺寸映射，请保持无缩放父节点，避免非预期的拉伸。
