# 格子规则 + 有机膜动画

打开 `OrganicGridDemo.unity`（单独打开，不附加其他场景），Game 选 16:9，Play。
若尚未生成场景，使用菜单 `Tools > Cell Fusion > Create Organic Grid Scene`；当前未命名场景需先保存。

- WASD / 方向键：四向移动，只能进入空格。
- 空格键或 Evolve：同步推进一代；过渡期间暂时禁止移动与推进。
- R / Reset：重置。
- Enable births：关闭后可单独试验死亡和存续。
- Show grid / Show neighbour counts：查看格子与八邻域计数。

初始蓝色 2×2 是稳定结构，金色圈是出生目标。玩家从出生点向左移动一格，再按空格，即可给目标补上第三个邻居。重置后直接推进不会使目标出生。达成目标后仍可继续试验。

规则为 B3/S23：空格 3 邻居出生，活细胞 2/3 邻居存活，其他死亡。棋盘边界外视为空。玩家是永久活邻居，不会死亡、不允许在玩家格出生；移动本身不推进一代。

逻辑只处理 bool[49] 与玩家格；Shader 绘制膜，独立绘制固定在每格中心的核。膜连接不会合并逻辑细胞。新细胞从旧邻居平均位置长向目标格，核稍晚出现；死亡核与膜一起淡出、收缩；玩家移动保留一小段收缩尾部。所有细胞从同一旧棋盘同步演化。

本例为 7×7 独立玩法试验，没有墙、撤销、正式关卡管理、背景折射或碰撞体。目标为演化结束时指定格出生，不是玩家到达出口。
`Generation Duration` 和 `Fusion` 可在 Board 组件上调节。默认约半秒一代。
Shader 每像素最多遍历 49 格，适合小棋盘验证；扩大地图前应改为贴图传递棋盘或局部采样。
菜单不会覆盖已有场景。英文面板避免依赖尚未安装的中文字体。
