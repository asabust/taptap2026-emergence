# 共用玩法与同场景试玩

更新：2026-11-03。玩法以 `LevelPlaySession` 为唯一真值，正式 Gameplay 和编辑器试玩共用规则；两个 Demo 仅作表现原型参考。

## 在 LevelEditor 中试玩

1. 打开现有 `Assets/Scenes/LevelEditor.unity` 并运行，不需要重新生成场景。
2. 加载 JSON 或编辑未保存草稿，配置玩家、完整目标、三个规则开关与额度。
3. 点击“试玩当前草稿”。配置输入会先应用；尺寸变化需先明确调整。校验失败保留编辑态并显示错误。
4. 在 Game 窗口操作。结束后点击“结束试玩 · 返回编辑”，保留原草稿、画笔和目标选择；试玩状态、历史丢弃，不写回草稿或正式进度。

切换不保存／重读 JSON、不切 Scene。R 恢复本次试玩起点，重新试玩使用最新草稿。退出 Play 前仍需保存要保留的编辑。

## 键盘与选择模式

| 输入 | 行为 |
| --- | --- |
| 方向键／WASD | 移动一格；长按不连发 |
| Space | 迭代一次 |
| B | 放置分身模式，点击合法格创建一个 |
| N | 分身上限为 1 时直接回收已有分身；大于 1 时进入点选回收，即使当前只剩一个 |
| Z | 撤销最近成功的迭代／分身创建／回收 |
| R | 恢复初始状态、清空历史 |
| Esc | 选格时取消、移动时暂停、暂停时继续；规则面板中关闭规则 |

回收不限距离，仅能回收自己的存活分身。正式 HUD 隐藏回收按钮，使用 N；编辑器诊断界面保留按钮。非法选格保持当前模式，成功选一次后回到移动模式。选择中可 Z 撤销并返回移动；R 需先退出选择。暂停中先继续，再执行普通操作。

同帧最多执行一次请求，优先级为 Reset → Undo → Cancel → Pause → Clone → Recycle → Iterate → Up → Right → Down → Left → Select；实际能否执行还受暂停、选格、胜败及上层模态界面约束。移动／演化过渡期间会拦截普通操作，Z／R 可直接恢复准确状态。

## 演化与撤销

- 每关孤独死亡、拥挤死亡、局部繁殖三个开关独立。`localBirth` 缺失即关闭，新建草稿默认三项开启。
- 只有开启局部繁殖时，玩家八邻域的有效空地才在恰三邻居时诞生普通细胞。死亡与出生读取同一旧状态，新生不参与本轮计数、死亡格不立即重生。
- 玩家和分身都贡献邻居；玩家不死亡。分身按普通细胞演化，但保留来源标记，存活数量受 cloneLimit 限制。
- 分身候选格须在玩家八邻域、为空地且经四向地形连通；临时细胞占位不切断地形连通。
- 创建、回收、迭代分别保存操作前完整快照，最多 100 次；移动不单独记历史。Z 恢复最近一项，包括玩家位置、分身来源与轮数，不再按整轮撤销。
- 达到迭代上限可继续移动、创建／回收；尝试超限迭代才失败，不改变布局、不添加历史。胜败后可撤销／重置。

## 棋盘与表现

正式 Prefab HUD 使用静止的轴对齐方形渐变地砖与蓝色交叉终点。玩家为柔橙色，普通细胞为蓝紫色，分身／细胞核颜色较深；细胞膜融合、移动拖尾、出生／死亡过渡是表现，不合并逻辑占位。普通细胞有轻微呼吸效果。

玩家八邻域有效地块沿原色提亮，表示几何影响范围，不保证繁殖、空位、连通或额度条件满足；放置与回收使用独立选格标记。展示取景／拾取由 `LevelBoardFrame` 协调，逻辑坐标仍为左下原点方格。

## 独立 Gameplay 与测试样例

打开 `Assets/Scenes/Gameplay.unity`，组件 `LevelPlayScreen.levelId` 决定加载的 JSON；现有场景无需重建，测试不会写正式通关进度。

`stage6_probe` 已移出正式目录，固定样例位于 `Docs/Tests/Fixtures/stage6_probe.json`，供逻辑和流程检查读取。如需在编辑器手动加载，可复制为临时 Levels 文件，使用后删除，不加入正式 Catalog。

样例布局：玩家 `(0,1)`，普通细胞 `(0,0)`、`(2,1)`，细胞目标 `(1,0)`，玩家终点 `(3,1)`；分身上限 1、迭代上限 2。

1. 创建分身于 `(1,0)`。
2. 原位按 Space；阻路的 `(2,1)` 因孤独死亡。
3. 向右移动三次到 `(3,1)`，每次等待移动完成，全部目标成立。
4. 此时 Z 恢复迭代前玩家和细胞布局，保留分身；再按 Z 撤销分身创建。R 恢复初始布局并清空历史。
