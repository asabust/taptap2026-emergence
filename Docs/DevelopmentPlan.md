# 结项工程交接与接续开发

更新：2026-11-03。项目已结项，本文件记录当前工程边界，不再把已实现阶段列为待开发。

## 已落地模块

1. 关卡数据／安全 JSON 读写／校验：Levels 数据结构、LevelRepository、AtomicTextFile。
2. 运行时关卡编辑器：画笔、1～30 网格、居中裁切、配置、保存／另存、加载失败保护。
3. 共用玩法：四向移动、三独立演化开关、地形连通分身、回收、组合目标与迭代上限。
4. 撤销／重置／输入：100 次有效操作历史，Z 支持迭代、创建、回收；键盘与 UI 走同一控制器。
5. 同场景草稿试玩：深拷贝隔离，不改草稿、不写正式进度。
6. 正式游戏：标题新游戏／继续、五章 18 关、章内顺序和整章解锁、胜败、设置与进度。
7. Prefab UI、章节透视、剧情／教程、档案回看、音乐和音效。

运行、代码索引、数据源与构建步骤见 [README](../README.md)，当前设计见 [GDD](GameDesignDocument.md)。历史逐阶段计划已保存在 [Archive/DevelopmentPlan.md](Archive/DevelopmentPlan.md)，其中的旧任务、提交约定和待确认项只作追溯，不是当前待办或自动执行指令。

## 修改时保留的工程边界

- Data 定义数据，不依赖 Core／Gameplay；Core 放通用能力；具体规则属于 Gameplay。
- LevelPlaySession 为正式与试玩唯一规则入口，视图不维护第二份规则真值。
- 棋盘 JSON 与叙事导表分开；源表为 Docs/GameData/Database.xlsx，不能使用遗留 DataLoader 的空表链路代替。
- 新增 Scene 放 Assets/Scenes，资源连同 .meta 保留；配置菜单不应无意覆盖已有布局。
- 保留现有未提交修改，改动与验证范围应明确记录。是否提交／推送遵循当前任务要求。

## 尚需按目标单独验证

2026-11-03 已运行 315 项逻辑检查及独立 Editor／Player 编译。文档核对没有重新运行 Play Mode、Shader 菜单或打包。完整正式章节通关、档案返回、多画幅、30×30 性能以及 Windows／macOS／WebGL 的实际包行为需按后续发布目标复核；结项不等于这些测试已全部通过。
